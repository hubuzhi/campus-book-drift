# 校园图书漂流小程序

一个基于**微信原生小程序**的校园二手书共享平台：浏览书库、按分类筛选、搜索、
发布图书、加入书架、借阅与归还状态流转。

> 数据层目前使用 `wx.setStorageSync` 本地存储实现，结构上与云开发一致，
> 后续接入云数据库只需替换 `utils/store.js` 的实现，页面代码无需改动。

## 技术点

| 分类 | 说明 |
| --- | --- |
| 框架 | 微信原生小程序（WXML / WXSS / JS） |
| 页面 | 5 个页面：书库、图书详情、发布、我的书架、我的 |
| 组件 | 自定义组件 `book-card`（properties 接收数据、`triggerEvent` 回传点击） |
| 导航 | tabBar 四个入口 + `wx.navigateTo` 带参跳转详情 |
| 数据 | 本地存储封装成数据层 `utils/store.js`（增删改查 + 收藏状态） |
| 交互 | 下拉刷新、触底分页加载、搜索过滤、分类筛选 |

## 目录结构

```
├── app.js / app.json / app.wxss     全局配置与启动逻辑
├── components/book-card/            图书卡片自定义组件
├── pages/
│   ├── index/                       书库：搜索 + 分类 + 分页 + 下拉刷新
│   ├── detail/                      详情：收藏、借阅/归还
│   ├── publish/                     发布：表单校验 + 封面配色
│   ├── shelf/                       书架：我的收藏 / 我发布的
│   └── profile/                     我的：登录态与统计
└── utils/store.js                   数据层（本地存储实现）
```

## 运行方式

1. 打开**微信开发者工具** → 导入项目 → 选择本目录
2. AppID 选「**测试号**」或「不使用 AppID」（游客模式）
3. 编译即可运行，无需后端与网络
